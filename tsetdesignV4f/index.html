10 套 Agent 主页。不换皮 —— 每套都重新追问一个问题:
如果界面由 AI 的本体论决定,它会长成什么样?
v3.7.1
01
FŁUX
Token Stream — 界面不是布局,是时间
页面即一条永不停歇的 token 流,每个字符实时被预测、采样、沉淀。无窗口、无卡片、无导航。
 R·768
02
VESSEL
Latent Space — 导航即检索
agent 的能力是一个三维向量空间,主页是空间本身。交互不是点击,是航向某个聚类。
 σ=0.31
03
ORACLE
Probabilistic UI — 不确定即是形态
只有确定的内容才清晰。不确定的部分以概率云雾呈现,悬停让它坍缩成文字。
 CoT×8
04
ECHO
Visible Thought — 页面就是思维链
每次打开都是一次新的推理。主页从前提长出结论,思考过程本身即内容。
 Θ(x̄)
05
PRISM
Attention Field — 注意力即排版
界面由注意力强度驱动变形:被注视的内容放大清晰,其余收缩模糊。你移动,页面重排。
 5 voices
06
CHOIR
Ensemble — 一个 agent,五个声部
规划者、执行者、批判者……五条声道复调并行,在节拍上汇成交响。主页是一场合奏。
 LTM:1.2TB
07
GROVE
Memory Garden — 记忆是生长出来的
主页是一棵活树。高频记忆结出明亮的果实,陈旧的记忆慢慢枯萎、坠落、被遗忘。
 iter#284
08
GENESIS
Recursive Prototype — 展示设计自身
打开页面时,它从线框草图开始自我迭代,把设计决策摊开给你看。每次刷新都是新的演化。
 seed:0xA3F1
09
DUNE
Generative Interface — 没有模板
地形、风、以及内容的位置,全部由噪声函数现场生成。同一份代码,每次打开都是不同的主页。
 ε=0.1
10
GRADIENT
Reward Loop — 界面在进化
主页是一个强化学习回路。元素因你的反馈获得或失去权重,界面本身在优化它自己。
