AI-Native Design · Ten Philosophies

Agent 主页的
十种 原生形态

当界面不再为「导航」而设计，而是为「意识」而设计 —— 十个关于 Agent 主页的假设，每一种都不是换皮，而是一次世界观的重置： 流体、对话、潜在空间、令牌、生长、编织、共振、群智、时间晶体，与虚空。

01 / FLUID

生成流体

Generative Fluid

界面不是窗口，是一片会呼吸的场。UI 从流体的扰动中浮现，又在交互后重新溶解。
02 / DIALOGUE

对话即界面

Conversation as Interface

没有导航、没有按钮，只有一个正在思考的光标，和 Agent 面向你的自述流。
03 / LATENT

潜在空间

Latent Space

能力是散布在语义空间里的点。导航即旅行，靠近一个想法，它会为你绽放。
04 / TOKEN

令牌流

Token Stream

以最细粒度的单元为建材。你看见的不再是「文字」，而是正在被采样的下一个 token。
05 / GROWTH

有机生长

Organic Growth

界面像珊瑚一样自行分叉。滚动即是生长，触碰节点，让它开花结果。
06 / WEAVE

编织

Weave

人类语境与机器记忆，是数条被反复穿梭的线，最终编成同一块织物。
07 / RESONANCE

共振频率

Resonance

Agent 是一件待调校的乐器。每个能力都是一段谐波，你的触碰就是定音。
08 / SWARM

粒子场

Swarm

上千个微小的智能单元自我组织，在秩序与混沌之间，凝聚成文字与答案。
09 / CRYSTAL

时间晶体

Time Crystal

过去、现在与未来共存在同一块晶体的不同切面上。旋转它，即是穿越状态。
10 / VOID

呼吸的空

Breathing Void

极致的留白。Agent 不是功能，而是一种在场。空，也是有重量的。
