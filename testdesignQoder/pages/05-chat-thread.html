An agent that works the way a good engineer does — in the open.

Loom reads your repository, runs code in a sandbox, and shows every step it takes. Nothing is hidden behind a progress bar.

It keeps a persistent thread per project, so context survives the handoff from your laptop to a teammate's. Tool calls are expandable — click any one to see the exact files, diffs and test output behind the answer.
