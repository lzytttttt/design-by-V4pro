01

ManifestWhat we stand behind

Every agent we have used guessed. It guessed at a function it never opened, guessed at a test it never read, and handed us a diff that compiled and lied. So we built the opposite.

The agent reads a file end to end before it is allowed to touch it. It records the hash of the revision it read. If the bytes on disk changed while it was thinking, the write is refused and the run stops.

No cloud workspace. No index of your private code. No background process. The log lives in ./agent01/runs/ and belongs to you.

Placard 01

We do not write to a file we have not read in full.

Enforced in the writer, not the prompt. The edit call carries the read hash. Mismatch: refuse.

02

The machineFour motions, in order

Plate A · recombines the same nine shapes
  1. 01

    Read

    Walks the tree, resolves imports, opens every candidate file in full. No window, no sample.

  2. 02

    Plan

    A numbered list of edits in plain language, each tied to one file and one reason.

  3. 03

    Write

    Unified diffs, one per file, held until you approve. Hash mismatch: refused.

  4. 04

    Verify

    Runs your own tests and type checks, then prints exit codes whether or not they flatter us.

Commands: agent01 read agent01 plan agent01 diff agent01 revert
